See your Markdown rendered in real-time as you type. The preview panel automatically updates with every change, so you can see exactly how your document will look without switching between editor and preview.

### 📄 PDF Export
Convert your Markdown to beautiful PDF documents with professional formatting. Perfect for creating client deliverables, documentation, or any professional content that needs to be shared as a PDF.

### 🌐 HTML Export
Generate clean, responsive HTML files perfect for web publishing. The exported HTML includes embedded styles for consistent appearance across different platforms.

### 📝 Word Export
Create Word documents (.docx) for easy sharing with non-technical colleagues. The Word export maintains your formatting and structure, making it easy to collaborate with team members who prefer Microsoft Word.

### 🖼️ Image Support
Easily insert images into your Markdown documents. Use the command palette to insert images from your file system, or simply drag-and-drop images directly into your document.

### 💻 VS Code Integration
Deep integration with VS Code means you can use all your favorite extensions and workflows alongside Markdown Editor Pro. Enjoy the full power of VS Code while working with Markdown.

## Usage

### Opening the Editor
1. Open any Markdown file (.md) in VS Code
2. Use the command palette (Ctrl+Shift+P or Cmd+Shift+P)
3. Search for "Markdown Editor Pro: Open Editor"

### Live Preview
- The preview panel automatically appears when you open a Markdown file
- It updates in real-time as you type
- Supports all GitHub Flavored Markdown features

### Exporting Documents

#### Export to PDF
1. Open a Markdown file
2. Use the command palette and search for "Markdown Editor Pro: Export to PDF"
3. Choose a location to save your PDF file

#### Export to HTML
1. Open a Markdown file
2. Use the command palette and search for "Markdown Editor Pro: Export to HTML"
3. Choose a location to save your HTML file

#### Export to Word
1. Open a Markdown file
2. Use the command palette and search for "Markdown Editor Pro: Export to Word"
3. Choose a location to save your Word document

### Inserting Images
1. Open a Markdown file
2. Place your cursor where you want to insert the image
3. Use the command palette and search for "Markdown Editor Pro: Insert Image"
4. Select an image file from your system
5. The image will be inserted with proper Markdown syntax

## Requirements

- VS Code 1.75.0 or higher
- Node.js (for development)

## Extension Settings

This extension contributes the following settings:

- `markdown-editor-pro.preview.enabled`: Enable/disable live preview
- `markdown-editor-pro.export.pdf.format`: PDF page format (A4, Letter, etc.)
- `markdown-editor-pro.export.html.includeStyles`: Include CSS styles in HTML export
- `markdown-editor-pro.export.word.format`: Word document format options

## Known Issues

- Image paths may need adjustment when moving files between different operating systems
- Some advanced Markdown features may not render perfectly in all export formats
