# Change Log

All notable changes to the "Markdown Editor Pro" extension will be documented in this file.

## [1.0.0] - 2024-01-01

### Added
- Initial release of Markdown Editor Pro
- Live preview panel with real-time updates
- Export to PDF functionality
- Export to HTML functionality  
- Export to Word (.docx) functionality
- Image insertion with drag-and-drop support
- Full GitHub Flavored Markdown support
- Syntax highlighting for code blocks
- Distraction-free writing environment

### Features
- Automatic preview updates as you type
- Professional PDF generation with proper formatting
- Clean HTML export with embedded styles
- Word document export capability
- Easy image insertion from file system
- Support for tables, task lists, footnotes, and more

## [1.0.1] - 2024-01-02

### Fixed
- Fixed image path handling on Windows
- Improved PDF generation performance
- Better error handling for export functions
- Fixed syntax highlighting in preview

### Added
- Support for relative image paths in workspace
- Auto-detection of Markdown files
- Improved preview styling

## [1.1.0] - 2024-01-15

### Added
- Custom CSS themes for preview
- Export presets (custom formatting options)
- Image resizing in preview
- Table of contents generation
- Word count and statistics

### Improved
- Faster preview rendering
- Better PDF formatting
- Enhanced image handling
- Improved accessibility

## [2.0.0] - 2024-02-01

### Major Features
- Split view editing (editor + preview side by side)
- Custom themes and color schemes
- Advanced export options
- Image optimization
- Markdown linting
- Custom snippets
- Keyboard shortcuts
- Settings and preferences

### Performance
- Significantly improved rendering performance
- Reduced memory usage
- Faster export times
